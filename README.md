# UniTrack 📚🎓

*A simple, offline University Schedule & Attendance Tracker.*

UniTrack is an Android app designed to help students manage their **class schedules, attendance, and marks** in one place. It’s built to work **fully offline** using SQLite3, so your data stays on your device without needing internet access.


## ✨ Features

* **Schedule Management**

  * Add, edit, and manage your university class schedule.
  * Automatically see your upcoming classes.

* **Attendance Tracking**

  * Get notifications during class time with quick actions: **Attended ✅** or **Skipped ❌**.
  * Track your attendance percentage per course.

* **Marks & Performance**

  * Record marks for each course.
  * View your academic progress over the semester.

* **Friend Schedule Sharing (Planned 🚀)**

  * Each schedule will generate a unique **64-bit share code**.
  * Entering the code will copy the schedule to another user’s app.


## 🛠️ Tech Stack

* **Framework:** Flutter
* **Database:** SQLite3 (offline storage)
* **Platform:** Android (iOS support planned later)

## 🏗️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/UniTrack.git
   cd UniTrack
   ```
2. Install dependencies:

   ```bash
   flutter pub get
   ```
3. Run on Android:

   ```bash
   flutter run
   ```
